## Installation

Open RuneLite's **Plugin Hub**, search for **Spectator Oculus Hints**, and install the plugin.
You can also view its [Plugin Hub listing](https://runelite.net/plugin-hub/show/specatator-oculus).

## Features

- Hide top-left hover text while using spectator oculus views.
- Optionally restore overhead player names.
- Show saved Ground Markers at the spectator camera when it is far from the logged-in player.
